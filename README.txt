Add items to items.json, for example:

[
  {
    "title": "Name",
    "cat": "ویندوز",
    "version": "1.0",
    "size": "25 MB",
    "date": "1405/08/01",
    "cover": "https://example.com/cover.jpg",
    "desc": "Short description",
    "links": [ { "label": "دانلود", "url": "https://example.com/file.exe" } ]
  }
]

cat must be one of: ویندوز, اندروید, مک, بازی
Upload index.html and items.json together to the same GitHub repo.
